# Продвинутое веб-приложение для карты точек доступа Wi-Fi

## Описание проекта
Продвинутое Flask веб-приложение для отображения интерактивной карты города с возможностью профессионального анализа точек доступа Wi-Fi. Включает систему интеллектуальной триангуляции для повышения точности координат на основе множественных измерений силы сигнала.

## Основные функции
- Интерактивная карта города на основе Leaflet.js и OpenStreetMap
- **НОВОЕ**: Постоянное хранение данных в PostgreSQL базе данных
- **НОВОЕ**: Расширенные данные точек доступа (MAC-адрес, тип шифрования, RSSI)
- **НОВОЕ**: Интеллектуальный алгоритм триангуляции для уточнения координат
- **НОВОЕ**: Цветовая индикация уверенности в координатах (🔴🟠🟢)
- **НОВОЕ**: Автоматическое обновление координат при получении новых измерений
- Добавление точек доступа Wi-Fi кликом по карте
- GET API для программного добавления точек доступа
- Отображение всех точек на карте с детальной информацией
- Страница со списком всех точек доступа с расширенными данными

## Архитектура
- **Backend**: Flask с CORS поддержкой + SQLAlchemy ORM
- **База данных**: PostgreSQL с таблицами WifiPoint и SignalMeasurement
- **Frontend**: HTML/CSS/JavaScript с Leaflet.js
- **Алгоритмы**: Система триангуляции на основе RSSI измерений
- **Карты**: OpenStreetMap через Leaflet.js

## API Endpoints

### GET /api/points
Возвращает все добавленные точки доступа в формате JSON с полными данными включая:
- Основную информацию (название, пароль, координаты)
- Технические данные (MAC-адрес, тип шифрования)
- Метрики качества (количество измерений, уверенность в координатах)

### GET /api/add_point
Добавляет новую точку доступа или обновляет существующую.

**Основные параметры:**
- `lat` (обязательный) - широта (число)
- `lng` (обязательный) - долгота (число) 
- `mac` (обязательный) - MAC-адрес точки доступа
- `name` (опциональный) - название точки доступа
- `password` (опциональный) - пароль для подключения
- `encryption_type` (опциональный) - тип шифрования (WPA2, WPA3, WEP, Open, Unknown)
- `rssi` (опциональный) - мощность сигнала в dBm (от -100 до 0)

**Пример создания новой точки:**
```
/api/add_point?lat=55.7558&lng=37.6176&mac=00:11:22:33:44:55&name=Кафе WiFi&password=mypassword123&encryption_type=WPA2&rssi=-45
```

**Пример обновления координат существующей точки:**
```
/api/add_point?lat=55.7560&lng=37.6180&mac=00:11:22:33:44:55&rssi=-38
```

### POST /api/add_point
Альтернативный способ добавления точки через POST запрос с JSON данными.

## Алгоритм триангуляции
Система использует интеллектуальный алгоритм для повышения точности координат:

1. **Сбор измерений**: При получении RSSI данных создается новое измерение
2. **Оценка расстояния**: RSSI конвертируется в примерное расстояние
3. **Взвешенное усреднение**: Координаты пересчитываются с учетом силы сигнала
4. **Расчет уверенности**: Система вычисляет уровень доверия к координатам
5. **Цветовая индикация**: Маркеры отображаются разными цветами:
   - 🟢 Зеленый: высокая уверенность (>70%)
   - 🟠 Оранжевый: средняя уверенность (30-70%)
   - 🔴 Красный: низкая уверенность (<30%)

## Технические детали
- Сервер запускается на порту 5000
- Карта центрирована на Москве (55.7558, 37.6176)
- Маркеры отображаются с цветовой индикацией по уровню уверенности
- При клике на маркер показывается popup с полной информацией
- Форма добавления точки появляется при клике по карте
- MAC-адрес используется как уникальный идентификатор точки доступа
- Поддержка автоматического обновления координат при новых измерениях

## База данных
### Таблица WifiPoint
- `id` - уникальный идентификатор
- `mac_address` - MAC-адрес (уникальный)
- `name` - название точки доступа
- `password` - пароль для подключения
- `encryption_type` - тип шифрования
- `lat`, `lng` - координаты (обновляются автоматически)
- `measurement_count` - количество измерений
- `confidence_level` - уровень уверенности в координатах
- `created_at`, `updated_at` - временные метки

### Таблица SignalMeasurement
- `id` - уникальный идентификатор
- `wifi_point_id` - ссылка на точку доступа
- `lat`, `lng` - координаты измерения
- `rssi` - мощность сигнала в dBm
- `measured_at` - время измерения
